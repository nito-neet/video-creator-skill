# ビデオクリエイター（video-creator）

Claude Code に「動画を作って」と言うだけで、**文字が動いて意味を伝えるショート動画**を
企画から MP4 の書き出しまで作り切るスキルです。尺は **15秒・30秒・60秒** から選べて、
縦（9:16）と横（16:9）を同時に作れます。

BGM も効果音も、その場で合成します。音源を用意する必要はありません。
サイトの URL を渡すと、**そのサイトのロゴ・画面・カード画像を自動で取ってきて**動画に載せます。

---

## 入れ方

**GitHub から取る場合（おすすめ・更新も楽）**

ターミナルで次の1行を実行します（URL は配布時の案内のもの）。

```bash
git clone <このリポジトリのURL> ~/.claude/skills/video-creator
```

git が無い場合は、GitHub のページ右上「Code → Download ZIP」で落として、
展開したフォルダを次の場所に `video-creator` という名前で置きます。

- Windows: `C:\Users\<あなたの名前>\.claude\skills\video-creator`
- macOS / Linux: `~/.claude/skills/video-creator`

（`skills` フォルダが無ければ作ってください。フォルダ直下に SKILL.md がある状態が正解です）

そのあと Claude Code を開き直して、`/video-creator` と打つか「動画を作って」と言えば始まります。

**更新するとき**：git で入れた人は同じ場所で `git pull` するだけです。

---

## 動かすのに要るもの

最初に1回だけ確かめます。作業フォルダで次を実行すると、足りないものを教えてくれます。

```bash
node scripts/doctor.mjs
```

| 要るもの | 用途 | 入っていなかったら |
|---|---|---|
| **Node.js v22.18 以上** | 必須。これだけは無いと動きません | https://nodejs.org/ から LTS を入れる |
| **Chrome か Edge** | サイトから素材を取るときだけ | ふだん使っているもので大丈夫。無ければ Claude が「入れますか？」と聞いてきます |

**ffmpeg は要りません。** 動画ライブラリに同梱されているものを使います。

ブラウザが無くても**文字だけの動画として最後まで作れます**。
入れるかどうかは Claude が説明したうえで聞いてくるので、断っても大丈夫です。

初回は `npm install` に少し時間がかかり、書き出し用のブラウザ（約110MB）も自動で落ちてきます。
作業フォルダは 1 案件あたり 500MB ほど使います。

---

## 使い方

Claude Code にこう言うだけです。

```
動画を作って  https://あなたのサイト.com
```

このあと4つだけ聞かれます（尺 / 縦横 / 用途 / サイトの実物を使うか）。
答えると、台本と絵コンテを作って「これで進めていいですか」と1回だけ確認が入ります。
承認したら、書き出しまで止まらずに進みます。

サイトが無くても作れます。その場合は文字だけの動画になります。

---

## 出てくるもの

```
output/
├─ final-vertical.mp4      縦 1080×1920
├─ final-horizontal.mp4    横 1920×1080
├─ script.md               台本（どの言葉を、なぜ選んだか）
├─ beat-map.md             音と映像のタイミング表
├─ storyboard.md           カットごとの設計
└─ render-info.md          仕様・権利表記・作り直す手順
```

作り直したいときは `output/render-info.md` にコマンドが全部書いてあります。

---

## 中身

| フォルダ | 何が入っているか |
|---|---|
| `SKILL.md` | Claude Code が読む手順書 |
| `references/lessons.md` | 実際に作ったときに踏んだ失敗と、その直し方 |
| `references/production.md` | 表現・音・権利のルール |
| `references/asset-capture.md` | サイトから素材を取るときのコツ |
| `templates/` | そのまま動く動画プロジェクト一式 |

`templates/` には**カットの型が11種類**入っています（叩きつけ / 文字が1字ずつ消える /
間 / ロゴの登場 / 数字のカウント / 実物の画面を見せる / 積み上げ / エンドカード など）。

## 気をつけること

- **Remotion** という動画ライブラリを使っています。個人と少人数の会社は無料ですが、
  **従業員が一定数を超える会社は有償ライセンス**が必要です（https://remotion.dev/license）。
- サイトから素材を取る機能は、**自分のサイト・許可をもらったサイト**に対して使ってください。
- 動画に数字や社名を出すときは、出どころを確かめてから使います。
  スキルもそのように作ってありますが、最後は自分の目で確かめてください。

## うまくいかないとき

| 症状 | 見るところ |
|---|---|
| そもそも始まらない | 置き場所が `~/.claude/skills/video-creator` になっているか |
| `node scripts/doctor.mjs` で × が出る | 表示された「→」のとおりに用意する |
| 素材が取れない | `materials/explore/report.json` と、そこのスクリーンショットを見る |
| 文字が画面の端で切れる | `references/lessons.md` の A-1 / A-4 |
| 動画が作れたか分からない | `output/` に mp4 があるか見る |
