# production.md — 制作の詳細ルール

SKILL.md の各フェーズから参照する本体。

---

## §1 情報と権利のルール

- 実在の企業・団体・歴史・数字を扱う場合は、**書く前に確認して出典を `script.md` に残す。**
  確認できなかった情報は使わない。料金・店舗数など変わる数字には「※◯年◯月時点」を付ける。
- URL が渡されたら、ページ本文から **サービス名／数字／ベネフィット／CTA／ブランドカラー** を抽出する。
  ページ上で「イメージ」「実績値ではない」と書かれた数字は、事実として見せない。
- **実在ブランドの公式ロゴ・アイコン・写真は勝手に使わない。** 社名は通常のテキストで表示する。
  自社・依頼元のもの以外は、エンドカードに「※非公式の紹介動画です／◯◯は△△の商標です」と入れる。
  **依頼主自身のサービスなら、ロゴも画面も自由に使ってよい**（この注記も不要）。
- 画面の切り抜きに他社の製品名が写り込むことがある（講座名・連携先など）。
  依頼主が自分の表示として掲げているものをそのまま写す分には問題ないが、
  **動画側のテキストとして他社名を読ませる演出は入れない。**報告にも一言書く。
- 架空の商品を作る場合は、実在の製品名と重ならない造語にし、「※架空の商品です」と明記する。
- 参考動画は、構図・配色・コピー・音をまねしない。取り入れるのは「カットの長さの配分とリズム」だけ。
  参考 URL があれば、再生位置を細かく動かして画面の変化量からカットの切り替わり時刻を測り、
  その「リズムの型」を `output/reference-tempo.md` にまとめてから設計する（動画のダウンロードはしない）。
- **BGM を勝手に取得しない。** 音源の指定がなければ、BGM と効果音をプログラムで合成したオリジナルにする。

## §2 表現のルール

### 構成

- **字幕動画にしない。** 文字が下からフェードインするだけの構成は禁止。
- **1カット1メッセージ。** 1カットの日本語は 2〜12 文字。
  文章は意味の単位に分けて、見せる順番を再編集してよい。
- 表示する文字の総量の目安：**15秒で40〜90字 / 30秒で80〜160字**。
  注釈階層は数に入れなくてよいが、主役だけで筋が通る構成にする。

### 文字

- **文字の意味と動きを一致させる。**

  | 意味 | 動き |
  |---|---|
  | 大きい | 巨大化 |
  | 速い | 残像つき高速スライド |
  | 落ちる | 落下 |
  | 変わる | 回転 |
  | 広がる | 字間が開く |
  | 集まる | 散らばった文字が収束 |
  | 薄い | ぺしゃんこから開く |
  | 軽い | ふわっと浮く |
  | 消える | 消しゴムで消える |
  | 残らない | 1字ずつ消えて1文字だけ取り残す |
  | 積み上がる | 時差で下から積層 |

- **文字の大きさは3階層**（主役 / 補足 / 注釈）。サイズ差を大きくし、全カット同じ大きさにしない。
- **構図を毎回変える**：中央 / 左寄せ / 右寄せ / 縦書き / 上下分割 / 斜め / 巨大文字を画面外にはみ出させる。
  ただし**主要メッセージが読めなくなる見切れは禁止**。
  横幅いっぱいの行ばかりになると寄せの差が消えるので、**置く高さと大きさでも差を付ける**。

### 数字

- **数字は最重要素材。** ほかの文字の 1.5〜3 倍の大きさにし、カウントアップしてから画面に叩きつける。
- **実物の点数（サムネ・カード・項目）があるなら、数字と枚数を同期させる。**
  数字が1増える＝実物が1枚増える、が一致すると「量」が言葉ではなく画で伝わる。
  テンプレートでは `timeline.ts` の `GRID` と `gridFilled()` がこれをやっている。
  枚数と数字がズレていたら起動時に例外で落ちる。

### 背景

- 背景色を数カットごとに大胆に切り替える。
- 背景には関連する単語を薄く（不透明度 3〜12%）敷いてよい。
  **実物の画面を同じ不透明度で敷くのも有効**（CTA の背景など）。ただし 5% を超えると輪郭が出て競合する。

### 動きの部品と時間

- 叩きつけ（1.8倍→0.92→1.0）/ スライド / マスクで出す / 回転 / 字間の開閉 / 1文字ずつ時差 /
  カウンター / パネルワイプ / 文字を巨大化して次の場面の背景にする。
  **柔らかいバウンスを使いすぎない。**
- 動く時間の目安（30fps）：叩きつけ 4〜8f / スライド 5〜10f / マスク 6〜12f / 見せる時間 8〜25f。
- 読める時間を守る：短い語 0.3〜0.6秒 / 大事な語 0.5〜1秒 / **最後のCTAは1.5〜2.5秒止めて見せる**。

### 強弱

- 全編を最大テンションにしない。**強→強→中→「間」→強→最強→「間」→CTA** のように強弱を付ける。
- **0.1〜0.5秒、画面と音を止める瞬間を入れ、その直後に大きな切り替えを置く。**
- 最大テンションは1点だけにする。

## §3 音ハメのルール

- 先に「拍の目盛り」を決め、映像と音を**同じ目盛りから**作る。30fps × 120BPM ＝ 1拍15フレーム。
- **カットの切り替えを拍（15fの倍数）に置く。** 高速の連続カットは8分（約7.5f）や16分（約4f）を使う。
- タイミングは**1つのファイル（`timeline.ts`）で数字として管理**し、効果音の位置もそこから計算する。
  音声合成スクリプトが同じファイルを読むので、映像と音がズレようがない。
- 効果音は重要な動きにだけ付ける：

  | 動き | 音 |
  |---|---|
  | 叩きつけ | インパクト |
  | スライド | シュッ |
  | 回転 | スワイプ |
  | カウント | カチカチ |
  | 数字の確定 | 低音ヒット（本編最大音量） |
  | 積層 | 軽いクリック |
  | 収束 | 低いスウェル |

  **音の山は見た目の「着地」に合わせる。** アタック分（約12ms）だけ手前から鳴らすと山が合う。
- **画面が止まる「間」では、BGM のドラムも止める。** `timeline.ts` の `HOLDS` を映像と音が共有する。
- 仕上げ：ソフトクリップ（tanh）→ -1.5 dBFS に正規化 → 最後1秒フェードアウト。

## §4 アクセシビリティ

- 画面全体の明るさが激しく変わる点滅を、**1秒に3回以上続けない。**
  高速の連続カットは、**背景を固定したまま**文字や色見本だけを差し替える。
- **白いフラッシュは1回1〜2フレームまで。** 不透明度は 0.5 まで。
- 文字と背景のコントラストを確保する（7:1 以上を目安）。
- 小さい注釈を高速で出さない。

## §5 技術とフォルダ構成

- **Remotion + React + TypeScript。** フォントはローカルのものを使い、ネットワークに依存しない。
- 構成：

  ```
  src/config      色・フォント・BPM（theme） / 文言（copy） / タイムライン（timeline） / 素材の目録（assets）
  src/motion      動きの部品（index） / 見切れ防止（fit）
  src/components  背景・画面の切り抜き・サムネのグリッド・縦横の切り替え
  src/scenes      カットごとの見た目
  scripts         下見・素材切り出し・目録生成・音声合成・静止画出力
  public/assets   サイトから撮った素材
  public/audio    合成した音源
  materials       下見の結果・素材の並び順（動画には使わない作業ファイル）
  output          納品物
  ```

- **マジックナンバーをコンポーネントに散らさない。**
  カットの開始・長さ・見せ場のフレームは `timeline.ts` にまとめる。
- 縦横両方を作る場合は、**同じプロジェクトに別コンポジションとして追加**し、
  文言・タイミング・音声・素材を共通化する。差分はレイアウトだけ。

## §6 進め方（チェックリスト）

1. 伝えたい1文を決め、文章を意味の単位に分け、各語に重要度（1〜5）を付ける
2. `output/script.md`（表示テキスト一覧・重要度・出典）を作る
3. `output/beat-map.md`（BPM、BGMの展開、主要な音ハメ位置の表）を作る
4. `output/storyboard.md`（カットごとの 時間 / テキスト / 構図 / 動き / 背景 / 効果音 / 実物）を作る
5. **★承認を1回だけ取る**
6. 素材を撮る（URL がある場合）→ 目録を作り直す
7. Remotion で実装し、BGM と効果音を用意する
8. 型チェックを通す
9. **静止画を書き出して自分の目で見る。**直したら撮り直して再確認する
10. MP4（H.264・AAC）を書き出し、解像度・fps・フレーム数・音量のピークを確認する
11. **書き出した MP4 から直接フレームを抜いて最終確認する**
12. `output/render-info.md`（仕様・フォント・音・権利表記・修正内容・再生成コマンド）を作る

## §7 おまかせ設定（入力が空欄のとき）

| 項目 | 既定 |
|---|---|
| fps | 30 |
| BPM | 120（1拍 = 15フレーム） |
| 尺 | 15秒（450フレーム） |
| 向き | 縦（1080×1920）。両方作れるなら両方 |
| 書体 | 太いゴシック（Noto Sans JP Black / Bold） |
| 配色 | 高コントラスト。サイトがあればその実物 |
| CTA | 2秒以上止めて見せる |
| BGM | 合成オリジナル |

尺を変えるときは `src/config/theme.ts` の `DURATION` と、`timeline.ts` の拍の配分を両方直す。
15秒=450 / 30秒=900 / 60秒=1800 フレーム。
